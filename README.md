# AETHERRA — живая вселенная

Локальная веб-игра с видом сверху. Мир и жители отображаются с помощью Canvas 2D, логика прототипа работает прямо в браузере.

## Запуск с любой папки и USB-носителя

**Windows:** распакуйте проект в любую папку и дважды нажмите `AETHERRA.bat`. Путь и буква диска не фиксированы. Скрипт передаёт запуск `AETHERRA_START.ps1`, который ищет работоспособный Python в папке игры, виртуальном окружении, PATH и обычных папках установки. Если сервер не запускается, ошибка сохраняется в `AETHERRA_STARTUP.log`. Для игры без Python отдельно запустите `PLAY_OFFLINE.bat`.

**Без установки Python:** просто откройте `index.html` двойным нажатием. Это автономный offline-режим. Интернет и API-ключи не нужны.

При работе сервера сайт открывается по адресу http://127.0.0.1:8765/ , проверка состояния: http://127.0.0.1:8765/health .

**Переносимый Python:** можно разместить совместимую дистрибуцию Python в подпапке `python`. Python не входит в репозиторий.

## Возможности

- 20 автономных жителей на процедурной карте.
- Добыча древесины и постройка домов из общего запаса.
- Новый мир по seed, пауза, ускорение, масштабирование, перетаскивание.
- Сведения о жителях и домах, журнал событий.

## Состояние прототипа

Есть поиск путей по суше, запас еды и древесины, сбор ягод, голод и энергия, первые дома, сохранение мира в localStorage и ручной экспорт/импорт JSON. Разум жителей работает автономно на JavaScript; Cloud.ru DeepSeek-V4-Flash доступен как **советник по нажатию кнопки** при работающем Python-сервере и подключённом ключе. DeepSeek не управляет каждым тиком. Ещё нет развитой демографии, экономики, дипломатии и бесконечного роста поселений.

## Проверка

`python -m unittest discover -s tests -v` — проверяет выдачу index и endpoint health локального сервера. Для проверки движка браузера нужен отдельный JavaScript smoke test.

## Обновление через GitHub

- При запуске через `AETHERRA.bat` откройте интерфейс и нажмите **⚙ Обновление мира**. Программа проверит `main`, попросит подтверждение, загрузит ZIP конкретного коммита, проверит структуру архива, сделает резервные копии и перезапустит сервер.
- При запуске напрямую через `index.html` нажмите `UPDATE_AETHERRA.bat` в папке игры. Для этого необходимы Python и доступ к GitHub.
- Сменная флешка поддерживается: каталог определяется относительно BAT-файла, а не буквы диска.
- `.aetherra_backup/` содержит копии предыдущих файлов программы; пользовательские данные и другие файлы не переписываются.
- Для первой проверки установленной версии локального маркера может не быть — первое обновление скачает актуальную версию.
- Перед обновлением текущий мир автоматически сохраняется в браузере. Для надёжной резервной копии также используйте **📤 Экспорт** и храните JSON-файл отдельно.

Если скачивание не удалось, текущую версию можно продолжать использовать.

## Если AETHERRA.bat не запускается

Запустите `PLAY_OFFLINE.bat` — он открывает `index.html` напрямую без Python и установки зависимостей. Проверьте, что ZIP полностью распакован и `index.html` находится рядом с BAT-файлом. Если и он не запускается, откройте `index.html` вручную через браузер Chrome/Edge. При этом веб-обновление недоступно, для него нужен локальный сервер Python.

## Диагностика проблем запуска

Запустите `DIAGNOSE_AETHERRA.bat` из распакованной папки. Он создаёт рядом `AETHERRA_DIAGNOSTICS.txt` с результатами проверки наличия файлов, установленного Python и доступности адреса `127.0.0.1:8765/health`. Полные пути пользователя и переменные окружения не сохраняются. При необходимости отправьте содержимое отчёта разработчику.

Дополнительно, когда Python работает, можно выполнить `python diagnose.py` — получится подробный JSON-отчёт в том же файле. Запуск диагностики не меняет игру и не устанавливает зависимости.

## Модуль «Обновление мира»

В верхней панели игры нажмите **Обновление мира**. Откроется отдельное окно с установленной версией (SHA), последней версией GitHub, описанием изменений, проверкой и кнопкой установки. История изменений открывается по ссылке на GitHub. Для установки требуется запуск через AETHERRA.bat с работающим локальным сервером Python. Первый запуск после обновления может показывать «не определена», если у старой установки ещё нет файла `.aetherra_version`.

Важно: на текущем этапе мир не сохраняется, поэтому установка и перезапуск сбрасывают текущую симуляцию. При открытии `index.html` напрямую доступна только инструкция по обновлению с помощью `UPDATE_AETHERRA.bat`.

## Разум мира — Cloud.ru

Откройте игру через `AETHERRA.bat` (локальный сервер), нажмите **Разум мира**, вставьте API-ключ Cloud.ru в поле пароля и выберите **Подключить**, затем **Проверить**. Для безопасности ключ находится только в памяти серверного процесса и сбрасывается при его закрытии; браузер не сохраняет его. **Отключить** удаляет ключ из памяти. Проверка использует официальный endpoint `https://foundation-models.api.cloud.ru/v1/models` и определяет доступность `deepseek-ai/DeepSeek-V4-Flash`. Никакие запросы к ИИ от жителей на этом этапе не запускаются. Проверка API может тарифицироваться согласно условиям Cloud.ru. В режиме `PLAY_OFFLINE.bat` подключение недоступно.

### Проверка настоящего ответа DeepSeek

В меню «Разум мира» подключите ключ, затем задайте вопрос в разделе «Вопрос советнику мира» и нажмите «Спросить DeepSeek». Это **реальный, потенциально платный вызов** `/v1/chat/completions` Cloud.ru с ограничением генерации до 240 токенов. Ответ отображается как рекомендация; игровые действия не выполняются. Автоматических фоновых запросов нет. Ключ существует только в памяти локального Python-сервера.

## Перенос сохранений и резервные копии

Сохранения localStorage привязаны к адресу сайта. Сохранение из `file://` **не появляется автоматически** при открытии `http://127.0.0.1:8765/`. Для переноса нажмите **📤 Экспорт**, затем в другом режиме — **📥 Импорт** и выберите JSON. Автосохранение выполняется раз в 30 секунд, а **↶ Предыдущий мир** возвращает предыдущее сохранение после создания нового мира. Не очищайте хранилище браузера без экспорта данных. API-ключ Cloud.ru в JSON не включается.
