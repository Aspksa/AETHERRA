# AETHERRA — живая вселенная

Локальная веб-игра с видом сверху. Мир и жители отображаются с помощью Canvas 2D, логика прототипа работает прямо в браузере.

## Запуск с любой папки и USB-носителя

**Windows:** распакуйте проект в любую папку и дважды нажмите `AETHERRA.bat`. Путь и буква диска не фиксированы. Скрипт сначала ищет `python/python.exe` рядом с игрой, затем `.venv/Scripts/python.exe`, затем системный Python. Если Python отсутствует или сервер не запустился, откроет `index.html` напрямую в браузере.

**Без установки Python:** просто откройте `index.html` двойным нажатием. Это автономный offline-режим. Интернет и API-ключи не нужны.

При работе сервера сайт открывается по адресу http://127.0.0.1:8765/ , проверка состояния: http://127.0.0.1:8765/health .

**Переносимый Python:** можно разместить совместимую дистрибуцию Python в подпапке `python`. Python не входит в репозиторий.

## Возможности

- 20 автономных жителей на процедурной карте.
- Добыча древесины и постройка домов из общего запаса.
- Новый мир по seed, пауза, ускорение, масштабирование, перетаскивание.
- Сведения о жителях и домах, журнал событий.

## Ограничения v0.1

Это ранний прототип. Нет полноценного поиска пути, послойного строительства, устойчивой экономики, сохранений или Cloud.ru. Жители используют правила JavaScript, а не LLM. Для реальной симуляции потребуется доработка.

## Проверка

`python -m unittest discover -s tests -v` — проверяет выдачу index и endpoint health локального сервера. Для проверки движка браузера нужен отдельный JavaScript smoke test.
