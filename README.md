# AETHERRA — живая вселенная

Первый автономный веб-прототип с картой сверху. Без внешних зависимостей.

## Запуск на Windows

1. Установите Python 3.
2. Скачайте ZIP репозитория и распакуйте.
3. Дважды нажмите **AETHERRA.bat**.
4. Откроется браузер по адресу **http://127.0.0.1:8765/**. Для остановки нажмите Ctrl+C в консоли.

Альтернатива: `python server.py`.

## Возможности v0.1.0

- Процедурная карта с водой, лесом, камнями и травой; новый мир по seed.
- 20 жителей ищут деревья, собирают древесину, относят её на общий склад.
- Автоматическое строительство домов из общего запаса (12 древесины).
- Пауза, ускорение x1/x3/x8, масштабирование и перемещение камеры.
- Выбор жителя/дома, событийный журнал и ресурсы поселения.
- Всё выполняется локально; никакой API-ключ не требуется.

## Ограничения прототипа

Пути жителей и размещение построек пока упрощены. Пища не добывается, нет смерти, размножения, сохранений, физики строительства, полноценной экономики или облачного ИИ. Жители используют алгоритмическое поведение, а не большую языковую модель.

## Архитектура

`server.py` — локальный HTTP-сервер на Python; `index.html` — интерфейс Canvas и движок симуляции на JavaScript; `AETHERRA.bat` — запуск для Windows.
